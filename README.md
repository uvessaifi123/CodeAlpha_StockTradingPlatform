# Stock Trading Platform in Java

## Project Description:-
The Stock Trading Platform is a beginner-friendly Java application that simulates basic stock market operations. Users can buy and sell shares, check their available balance, and view their stock portfolio.

## Key Features:-
- Display stock price.
- Purchase shares.
- Sell owned shares.
- Track account balance.
- View total shares owned.
- Calculate total portfolio value.
- Interactive console menu.

## Technologies Used:-
- Java.
- Java Scanner Class.
- Loops.
- If-Else Conditions.
- Variables and Arithmetic Operations.

## How It Works:-
The user starts with a balance of Rs. 10,000. Each share costs Rs. 500. The user can select menu options to buy or sell shares and view their current portfolio.

## How to Run:-
1. Install Java JDK.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Open the terminal in the project folder.
5. Compile the program:
   `javac StockTradingPlatform.java`
6. Run the program:
   `java StockTradingPlatform`

## Learning Outcomes:-
- Understanding Java fundamentals.
- Using loops and conditional statements.
- Taking input using Scanner.
- Performing basic calculations.
- Building a menu-driven application.

## Disclaimer:-
This is an educational simulation and does not perform real stock market transactions.
